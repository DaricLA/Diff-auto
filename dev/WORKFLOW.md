# WORKFLOW 协作流程说明（用户/AI 双方操作手册）

> 用途：记录 Diff-auto 项目的日常协作流程——反馈怎么提、改动怎么做、怎么验证、怎么扩展。
> 新对话 AI 先读本文件 + PROGRESS + STRUCTURE + GOLD 即可完整接管项目。

## 1. 文档体系（4 份，缺一不可）

| 文档 | 位置 | 维护者 | 内容 | 用户动作 |
|---|---|---|---|---|
| PROGRESS.md | dev/ | AI | 项目进度、已完成、待办、约定 | 换对话时贴给 AI |
| STRUCTURE.md | dev/ | AI | main.py 行号索引（改代码定位用） | 换对话时贴给 AI |
| WORKFLOW.md | dev/ | AI | 本文件：协作流程 | 需要时翻看 |
| GOLD.md | dev/ | AI | 预期差异登记表（引擎应如何判定） | 只拍板：同意/不同意 |

> 关系：PROGRESS 管状态、STRUCTURE 管位置、GOLD 管预期、WORKFLOW 管流程。

## 2. 角色分工

- 用户（非程序员）：使用、发现问题、拍板、替换代码、测试机跑验证
- AI：分析问题、出代码（行号+原文+纯代码块）、维护 4 份文档、写测试用例
- 测试机：离线/无权限/无Python/只能跑免安装exe；路径 C:\diff\

## 3. 反馈作业流程（日常）

```text
使用工具 → 发现问题 → 填 FEEDBACK.txt → 提交GitHub → AI分析 → 修复/登记 → 回归验证 → 完成


**用户操作（4 步）**：

1. 发现问题（GUI 对比误报/漏报/崩溃，或 auto_run 批量异常）
2. 测试机打开 `C:\diff\FEEDBACK.txt`，按模板填一行
3. U 盘拷回 → 手机/电脑提交 GitHub（网页编辑即可）
4. 新对话贴 PROGRESS + STRUCTURE + FEEDBACK 新内容 → AI 分析

**FEEDBACK.txt 填法（一行一问题）**：

```text
日期 / 类型（误报/漏报/崩溃/建议）/ 严重度（1=不影响 2=影响判断 3=崩溃）/
场景一句话 / 期望 / 实际 / 涉及文件路径
```

**AI 收到后的处理**：

| 反馈类型 | 处理方式 |
|---|---|
| 引擎 bug（报错/崩溃/漏报） | 给行号+原文+替换 → 用户应用 → 重建 → 测试机验证 |
| 误报/漏报（分歧） | COM 复核 → 需拍板时给建议 → 用户点头 → 改引擎+登记 GOLD+补用例 |
| 建议/排版 | 低优先级队列，批量处理 |

## 4. 改动-验证标准流程

```text
改代码 → 用户提交 → Actions 构建3个exe → 测试机跑 regression.exe → 回传2份报告 → AI确认
```

1. 测试机准备：先手动打开 Excel 关激活弹窗 → **关闭 Excel 里打开的 l2_* 文件**
2. 双击 `regression.exe`（2~4 分钟）
3. 回传 `RULES_VERDICT.txt` + `L2_REPORT.txt`
4. **通关标准：金标准 14/14 + L2 149/149 全绿**，不绿继续修

## 5. 新功能扩展流程

```text
提需求(一句话) → AI评估方案 → 用户拍板 → AI出代码 → 应用提交 →
构建 → 回归(14+149) + 新用例 → 全绿 → 登记(4份文档) → 完成
```

**扩展铁律**：

- main.py 改动必须用户拍板 + 零行为变化 + 全回归
- 新功能必须配套测试用例（写进 regression.py，不靠运气）
- 改完必须测试机全绿才提交

## 6. 代码修改格式约定

- 文字给【行号 + 该行完整原文】定位；代码块内纯代码（无行号）——用户手机无法搜索
- 优先给"整函数替换"（函数名可定位，用户全选替换）
- 每次修改给出：改前原文 + 改后文本

## 7. 换对话标准开场（照抄）

```text
项目现状见：
dev/PROGRESS.md（最新）
dev/STRUCTURE.md（最新）
dev/GOLD.md（最新）
最新反馈见：FEEDBACK.txt（如有新增条目）
请分析最新反馈并给处理建议。
```

## 8. 常见坑（双方必读）

- 跑 regression 前必须关闭 Excel 中打开的 l2_* 文件（否则 Permission denied）
- 跑 auto_run 前先手动打开 Excel 关激活弹窗
- 诊断代码用完即删（如 _rule_diag），不留垃圾
- 版本号 VERSION 与功能号同步（当前 v3.99）
- AI 无法访问 GitHub：源码由用户从 Raw 复制粘贴
- GOLD.md 由 AI 维护，用户只需拍板；FEEDBACK.txt 由用户填写
```
